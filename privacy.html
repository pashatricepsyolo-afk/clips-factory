Privacy Policy

Clips Factory · effective 18 November 2026

Who uses the app

Clips Factory is a personal tool. Its only user is the owner, who connects his own YouTube channels. It is not offered to the public and no one else can sign in.

Google data we access

With the owner's consent the app requests the scope https://www.googleapis.com/auth/youtube.force-ssl and uses it only to:

  • identify the signed-in YouTube channel (to make sure videos go to the intended channel);
  • upload the owner's videos as private with a scheduled publish time;
  • read back the title, description, tags and status of those uploaded videos;
  • update or delete those videos at the owner's request.

Storage

OAuth tokens are stored only on the owner's own computer, in a local file outside the application's folder. Upload records (video id, scheduled time, status) are kept in a local database on the same computer. Nothing is stored on any server operated by Clips Factory.

Sharing

Google user data is not sold, not shared with third parties, not used for advertising and not used to train any model. It is transferred only to Google's own YouTube Data API to perform the actions above.

Revoking access and deletion

The owner can revoke access at any time at myaccount.google.com/permissions and delete the local token files; the app then has no further access.

Policy compliance

Clips Factory's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Changes

Any change to this policy is published on this page with a new effective date.
